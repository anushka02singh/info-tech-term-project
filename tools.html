Information Technology Tools Used in This Course

This page highlights the key information technology tools that I learned and worked with throughout this course. These tools are essential for modern web development and digital information systems.

Tools Covered

HTML5

HTML5 structures web page content.

Most useful feature: Semantic elements.

Tip: Always validate your HTML.

MDN | W3Schools

CSS

Controls layout, colors, and spacing.

Most useful feature: External stylesheets.

Tip: Avoid duplicate rules.

MDN | W3Schools

Bootstrap 4

Creates responsive layouts quickly.

Most useful feature: Responsive grid.

Tip: Combine with custom CSS.

Bootstrap | W3Schools

JavaScript

Adds interactivity to pages.

Most useful feature: DOM manipulation.

Tip: Test often.

MDN | W3Schools

PHP

Processes form data on the server.

Most useful feature: POST handling.

Tip: Sanitize inputs.

PHP.net | W3Schools

MySQL

Stores survey and project data.

Most useful feature: Persistent data storage.

Tip: Always test connections.

MySQL | W3Schools

Web Forms

Collects user information.

Most useful feature: Survey radio buttons.

Tip: Label everything.

Form Validation

Ensures clean and complete submissions.

Most useful feature: Preventing errors.

Tip: Use JS + PHP together.
