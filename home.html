Welcome to My Term Project

Project Overview

This website is the final term project for my information technologies course and brings together everything I have learned throughout the semester, including HTML5, CSS, Bootstrap 4, JavaScript, PHP, and MySQL. The site is organized into four main sections: Home, Info Tech, Interests, and About.

Project Purpose

The goal of this project is to demonstrate both technical skill and creative design while exploring how information technology and digital media impact everyday life. Each section of the site highlights different tools, concepts, and personal interests using modern, responsive web design techniques.

On This Website

  • Info Tech: Learn about open-source technology used in libraries and explore the various information tools covered in this course. You can also participate in surveys and view real-time results stored in a database.
  • Interests: A multimedia section featuring my personal interests, including videos, images, and screencasts presented in a responsive layout.
  • About: Get to know more about me through an introduction, fun facts, and a link to my personal portfolio.
